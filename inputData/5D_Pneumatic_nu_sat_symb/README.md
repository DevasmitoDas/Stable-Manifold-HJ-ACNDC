# 5D_Pneumatic_nu_sat_symb

This folder defines the control problem of *Saturation-Aware Stable-Manifold Optimal Control of a Hysteretic Soft Pneumatic Actuator* (Sakamoto & Das, ACNDC 2027).

| File | Role |
|---|---|
| `systemData.m` | **Script.** Option flags, physical parameters `par`, all design and simulation settings `cfg`, the problem `prob`, and the toolbox names `A, B, Q, R, dim, knum, radi, Initial_State, Time_int` |
| `buildProblem.m` | Chooses the route. `symbFlag = 1` uses the symbolic route (paper). `symbFlag = 0`, or a missing Symbolic Math Toolbox, uses the analytic route |
| `symbSetting.m` | Symbolic plant with σ(u) inside the drift. It forms the pre-Hamiltonian, solves ∂Hpre/∂ν = 0, substitutes ν*, and differentiates H̄ to get the canonical field |
| `symbCompile.m` | Substitutes Q_y and R_ν, compiles vectorised handles, and exports the derivation to `result/symbolic_generated/` |
| `numericProblem.m` | The same formulas written out by hand, with no toolbox. They agree with the symbolic output to about 1e-13 |
| `Decide_xi.m` | Seeds: ±e_i and 8 Halton directions, radius 2e-4 (18 seeds) |
| `f.m, g.m, HamF.m, HamG.m` | Files generated by `matlabFunction` for the nominal parameters (λ_h = 0.02, R_ν = 0.02), in the reference `_sym` style. P1 compares them with the runtime problem. They accept one column at a time |

Model (paper Sec. 2):

```
z = [theta; v; p; h; u],  nu = du/dt,  ua = sigma(u) = 0.5 + 0.5*tanh((u-0.5)/0.5)
thetadot = v
J vdot   = -k theta - c v + bp p + kh h + Bd d
pdot     = r := (-p + ku*sigma(u))/taup
hdot     = (Ah - gamma*s_eh(h))*r - beta*h*s_er(r) - lambda_h*(h - h_r)
udot     = nu
```

J = 0.02, k = 0.6, c = 0.08, b_p = 0.35, k_h = 0.25, τ_p = 0.2 s, k_u = 1, A_h = 1, γ = 0.2, β = 0.8, λ_h = 0.02 s⁻¹, h_r = 0, ε_h = ε_r = 1e-4.
The target is θ* = 0.35, so p* = 0.6 and u* = σ⁻¹(0.6) = 0.6013662770.
The cost uses Q_z = diag(80, 5, 2, 1, 0.2), R_ν = 0.02 and the scaling S = diag(0.35, 1, 0.6, 0.4, 0.6).
